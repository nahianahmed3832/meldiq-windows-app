**Not production-ready.** Implemented remediation is `0.3.0-readiness.1`, on branch `codex/windows-production-readiness-20261103`, runtime source `4af83b0437190b2d115eb65d3a63fe583f3c88f0`. This report distinguishes source fixes and automated evidence from provider/physical-device acceptance.

1. **Issues and root causes.** The [audit](WINDOWS_READINESS_AUDIT.md) covers every reported issue, affected components, severity and remediation. Confirmed defects include executable resource editing disabled in development/private builds; missing NSIS URI registration before first launch; browser-only Discord return storage; PayPal's application return URL blocked by popup navigation policy; device decisions stored only for a process; primary-monitor bounds used for secondary monitors; and a three-locale UI with substantial English literals. The unspecified `\\` still needs reproduction details; no matching crash evidence was identified. An unidentified “special permission” prompt cannot yet be classified as UAC, device permission or Windows publisher/SmartScreen UI.

2. **Implemented fixes.** Generated a canonical nine-size ICO (16, 20, 24, 32, 40, 48, 64, 128, 256); enabled executable resource editing while keeping QA binaries explicitly unsigned; wired installer/uninstaller/window assets. Added explicit per-user NSIS install/upgrade registration and ownership-aware uninstall cleanup, association refresh, runtime registration status, and a state-bound hosted browser handoff. Short-lived pending login proof is OS encrypted and resumes through the existing backend PKCE/one-use exchange after a cold restart. Linking still needs fresh account context after restarting. Discord's native broker now returns to the existing backend connection, preview, import, progress and retry flow, with consent cancellation/deadline and honest import scope. PayPal popup return/closure refreshes or confirms only the saved account-owned checkout, never URL tokens or client success claims. Device decisions persist, concurrent identical requests share a prompt, and settings can reset them. Window restoration respects the actual monitor/work area and maximized state. Removed retired commercial names from visible legacy membership/gift labels while retaining existing entitlements and API compatibility.
